# Velvet-Roast
A modern, responsive luxury café &amp; specialty coffee shop website crafted with pure HTML5 and CSS3—featuring zero-JS category filtering and a live cart drawer.
☕ Velvet Roast Café — Artisanal Coffee & Bakery Website"Brewed with Love, Served with Passion."A modern, responsive, high-end café and specialty roastery website built 100% with semantic HTML5 and modern CSS3—requiring zero JavaScript for interactive menu filtering, live shopping cart counting, and slide-over drawer navigation.✨ Key Features🎨 Aesthetic & Visual DesignWarm Specialty-Coffee Palette: Crafted with warm cream (#FAF7F2), soft beige (#F5EFE6), roasted coffee brown (#6F4E37), dark chocolate (#2C1E16), and subtle golden accents (#C89D54).Editorial Typography: Pairs Playfair Display for refined serif headings with Plus Jakarta Sans for clean, legible body copy.Smooth Motion & Micro-Interactions: Includes staggered hero entrance animations, card elevation hover states, smooth scrolling, and a pulsing live "Open Today" status indicator.⚡ Pure-CSS Interactivity (Zero JavaScript!)Interactive Menu Category Filtering: Switch seamlessly between All Items, Hot Coffee, Cold Coffee, Tea & Refreshments, Desserts, and Snacks & Bakery using pure CSS :checked sibling selectors.Live Pure-CSS Shopping Cart & Drawer:Add or remove any of the 15 menu items directly from the menu or the Customer Favorites showcase.Real-time item counter badge in the sticky navigation bar powered by CSS counter-reset and counter-increment.Slide-over order drawer featuring quantity selectors, item removal toggles, and instant pickup order confirmation.Responsive Mobile Navigation: Collapsible mobile menu drawer built with accessible label/checkbox state toggles.📄 Complete Sections IncludedSticky Glassmorphic Navbar — Brand identity, smooth anchor links, mobile menu toggle, and highlighted Order Now cart trigger.Hero Welcome Section — Full-bleed café photography, animated headline, dual CTAs (Explore Menu & Visit Us), and roastery highlights.About Our Café — Brand heritage story, café interior showcase, and three craftsmanship pillars (Fresh Ingredients, Premium Beans, Handcrafted Recipes).Artisanal Menu — 15 curated items across 5 filterable categories with photography, descriptions, pricing, and interactive Add to Cart buttons.Our Customer Favorites — Dark-chocolate luxury showcase highlighting the Signature Cappuccino, Caramel Macchiato, Chocolate Lava Cake, and Strawberry Cheesecake.Customer Reviews — Five-star guest testimonials with avatars and editorial styling.Opening Hours — Weekday and weekend schedules paired with an animated live open-status badge.Location & Contact — Address, phone, email, social links, embedded interactive map, and an HTML5-validated contact form with confirmation feedback.Footer & Coffee Club Newsletter — Quick links, café details, newsletter sign-up confirmation, and a smooth Back to Top button.🛠️ Tech StackHTML5: Semantic structure (<header>, <nav>, <main>, <section>, <article>, <aside>, <footer>), ARIA accessibility labels, and native form validation.CSS3: Custom properties (CSS Variables), CSS Grid & Flexbox, :checked and :target pseudo-class state machines, CSS Counters, @keyframes animations, and responsive media queries.Fonts & Icons: Google Fonts (Playfair Display & Plus Jakarta Sans) and crisp inline SVGs.📁 Project Structurevelvet-roast-cafe/
├── index.html      # Complete single-file application (HTML5 + embedded CSS3)
└── README.md       # Project documentation
